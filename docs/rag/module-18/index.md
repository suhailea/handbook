## How to Use This Module

1. **Case studies first.** Read each one and try to sketch the architecture before revealing the answer. This is interview-grade practice.
2. **Reference implementation.** Map the code back to the case study patterns. Notice which components recur across every design.
3. **Checklist.** Use it as a pre-launch audit for any RAG system you build.
