# Production-Ready RAG

This track teaches how to design, build, evaluate, and operate production-ready Retrieval-Augmented Generation systems. 18 modules covering every component from ingestion to deployment, with 10 real-world case studies and 100+ interview questions. Assumes you know the basic pipeline (Data → Chunk → Embed → Store → Retrieve → Generate). Goes deep into the engineering decisions behind every component.
