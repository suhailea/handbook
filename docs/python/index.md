# Python — Zero to Hero

<span class="badge-planned">🚧 Planned</span>

This track covers Python from fundamentals to advanced internals, following the dual-explanation format used across the handbook: every concept is explained first in plain English (intuition, analogies, zero jargon) and then in full technical depth (CPython internals, bytecode, C-level mechanics). Twelve modules take you from language foundations through data structures, functions, OOP, concurrency (including the GIL and asyncio), the import system, memory management, type hints, the standard library, and testing. All content targets Python 3.12+.

## Roadmap

- Module 1: Language Foundations — syntax, data model, everything is an object
- Module 2: Data Structures — lists, dicts, sets, tuples and their CPython internals
- Module 3: Functions & Scoping — closures, decorators, LEGB rule, *args/**kwargs
- Module 4: OOP & The Descriptor Protocol — classes, MRO, metaclasses, __slots__
- Module 5: Iterators, Generators & Comprehensions
- Module 6: Error Handling & Context Managers
- Module 7: Concurrency — GIL, threading, multiprocessing, asyncio
- Module 8: The Import System & Packaging
- Module 9: Memory, GC & Performance
- Module 10: Type Hints & Modern Python
- Module 11: Standard Library Power Tools
- Module 12: Testing, Debugging & Tooling
- Module 13: FastAPI — from first endpoint to production deployment
