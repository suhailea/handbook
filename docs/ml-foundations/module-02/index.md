# Module 2 — Deep Learning & NLP

You understand ML fundamentals. Now we go deeper — literally. Neural networks stacked dozens of layers tall, specialized architectures for images and sequences, and the revolution that made modern LLMs possible.

This module covers the essential architectures: how neural networks work mechanically, the specialized designs (CNNs for images, RNNs/LSTMs for sequences) that ruled for a decade, and why Transformers replaced them. Then NLP fundamentals — the text processing pipeline that feeds every language model.
