# Module 1 — LLMs & Prompting

Before we write a single line of agent code, we need to understand what we're actually working with.

TaskFlow's engineering team just got an OpenAI API key. The product manager wants a customer support agent by end of sprint. Before we reach for a framework or start writing tools, we need to answer three questions: What exactly is an LLM? How do we talk to it? And what do we put in front of it?

This module covers the fundamentals — not academically, but as the grounding you need before you can make any intelligent decision about your agent.
