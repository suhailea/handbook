# Node.js Runtime

This track takes you from the fundamentals of how Node.js works under the hood to production-grade patterns for performance, security, and observability. Each module builds on the last, finishing with capstone projects that tie everything together.

- [Module 1 — The Runtime](./module-01/) — V8, libuv, module systems, and package resolution
- [Module 2 — The Event Loop](./module-02/) — Phases, microtasks, blocking, and the threadpool
- [Module 3 — Async Patterns & Error Semantics](./module-03/) — Promises, cancellation, async context, and error handling
- [Module 4 — Buffers, Streams & Backpressure](./module-04/) — Binary data, stream pipelines, and real-time streaming
- [Module 5 — Networking & HTTP Internals](./module-05/) — TCP, HTTP keep-alive, timeouts, HTTP/2, and WebSockets
- [Module 6 — Performance & Diagnostics](./module-06/) — Profiling, heap analysis, GC tuning, and scaling strategies
- [Module 7 — FS, Child Processes & OS Boundary](./module-07/) — File system, process spawning, graceful shutdown, and executables
- [Module 8 — Security & Hardening](./module-08/) — Prototype pollution, supply chain, and HTTP hardening
- [Module 9 — Testing & Observability](./module-09/) — Built-in test runner, structured logging, OpenTelemetry, and debugging
- [Module 10 — Capstones](./module-10/) — Build a web framework, job queue, and LLM gateway from scratch

### Production Backend Patterns

- [Module 11 — Database Patterns](./module-11/) — Connection pooling, ORMs, transactions, migrations, and query optimization
- [Module 12 — Auth & Security](./module-12/) — JWT, OAuth 2.0, sessions, RBAC, and password hashing
- [Module 13 — API Design Patterns](./module-13/) — REST best practices, pagination, validation, GraphQL vs REST, file uploads
- [Module 14 — Real-World Middleware](./module-14/) — Validation (Zod), CORS, compression, rate limiting, request context
- [Module 15 — WebSockets & Real-Time](./module-15/) — ws, Socket.IO, rooms, real-time patterns, scaling WebSockets
- [Module 16 — Cron Jobs & Scheduling](./module-16/) — Scheduling, distributed locking, email, file storage, external APIs
- [Module 17 — DevOps & Deployment](./module-17/) — Docker, CI/CD, config/secrets management, health checks, monitoring
